# ccgtv-epg

Daily-built XMLTV programme guide for the [iptv-org India playlist](https://iptv-org.github.io/iptv/countries/in.m3u),
with channel ids rewritten to the playlist's `tvg-id` values so Kodi's IPTV Simple Client
matches them directly.

- Guide: `https://agpulkit95.github.io/ccgtv-epg/guide_in.xml.gz`
- Sources: public epgshare01 India feeds (IN4 preferred, IN1 fills gaps)
- Rebuilt every day at 07:00 IST by GitHub Actions

Personal project for one Chromecast with Google TV. Listings data belongs to the broadcasters.
